## Generated files

- `lesson/assets/*.png` and `lesson/assets/figures_data.json`: rebuild with `python lesson/make_figures.py`.
- `lesson/instructor/CALIBRATION.md` and `calibration.json`: rebuild with
  `python lesson/instructor/calibrate.py`.
- `races/demo/`: rebuild with `python races/demo/make_demo.py`.
- `LEADERBOARD.md`: rebuild with `python race.py leaderboard`.
